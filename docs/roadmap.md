# OpenBand Roadmap

This file records product direction, not delivery status. Track active work and completion in GitHub Issues/PRs.

## Near term — core workflow polish

- Pan interpolation modes for automation.
- Per-track color selection.
- Undo/redo for automation edits.
- Reliable MiniPlayer drag-to-seek.
- Stem separation → multi-track project flow.

## Next — creative workflow

- One-knob effect simplifiers built on existing plugin chains.
- Vocal reverb/shimmer additions where they fit the current DSP model.

## Long term — advanced integration

- AUv3 support on eligible Apple runtimes.
- Prompt → effect-chain generation.
- Mackie Control Universal hardware support.

Before implementation, each item becomes a bounded Issue/Spec Kit feature and is re-evaluated against current architecture and product priorities.
