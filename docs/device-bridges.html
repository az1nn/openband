The Bridge Motto

"The frontend has zero knowledge of whether it's running in Electron, Tauri, or a browser tab. Swap the backend by replacing one file."

OpenBand abstracts all native file system operations, hardware audio device enumeration, and patchbay routing through src/bridge/. Frontend components never import Node.js fs or desktop IPC APIs directly; instead, they consume OpenBandNative from @bridge.

Bridge Implementations

electron.ts

Electron Desktop

Delegates natively to window.electronAPI exposed securely via contextBridge preload script.

tauri.ts

Tauri Desktop Stub

Provides secure placeholder stubs warning and returning safe defaults for future Tauri migration.

browser.ts

Browser Fallback

Uses localStorage for project persistence and Web APIs for file downloads and device enumeration.

Audio Playback & Hardware Routing

universalAudio.ts

Universal Audio System

Singleton AudioContext with lazy initialization, cross-platform mixdown via OfflineAudioContext, and file export support across web and native.

hardwareIO.ts

Multi-Channel Patchbay

Enumerates audio input/output devices, sample rates, channel counts, and latency, supporting custom routing matrix connections.
