Overview

The OpenBand Graph Engineer is a zero-dependency (Node.js built-ins only) static analysis and architecture toolchain. It scans source files, route definitions, tests, and OpenSpec documentation to construct a directed graph of the entire repository. It enforces architectural invariants, detects circular dependencies and orphaned code, generates human-readable architecture documentation, and produces self-contained interactive inspection reports.

Step-by-Step Usage Guide

1. Build Graph

Scan and Serialize

Scans all tracked roots, computes file content hashes for incremental caching, and outputs .openband/graph.json.

node graph/cli.mjs build
2. Validate Architecture

Run Invariant Checks

Checks for desktop bridge violations (OB-GRAPH-001), dependency cycles (OB-GRAPH-002), and unlinked specs.

node graph/cli.mjs validate
3. Generate Docs

Auto Architecture Markdown

Produces docs/generated/ARCHITECTURE.md containing module summaries, route lists, and component reuse rankings.

npm run graph:doc
4. Interactive Report

Generate HTML Report

Produces .openband/graph-report.html with client-side search, dependency inspection panels, and Mermaid diagrams.

npm run graph:report

Edge Types

Edge Type Description Inclusions
import Static ES module import/export between internal modules. Deps, Dependents, Cycles, Orphans
require CommonJS require() of an internal module. Deps, Dependents, Cycles, Orphans
dynamic-import Dynamic import() of an internal module. Deps, Dependents, Cycles, Orphans
route Intra-app navigation resolving to an app/** screen. Deps, Render
test Test file referencing a source module. Deps, Coverage check
specifies OpenSpec markdown referencing a repository file. Traceability
uses JSX component usage (file renders an imported component). Deps, Impact, Render (excluded from cycles & orphans)

Validation Rules

OB-GRAPH-001 Error

Desktop Bridge Violation

Frontend modules (app/, non-bridge src/) must not import Node/Electron/Tauri APIs directly. Use OpenBandNative from `@bridge`.

OB-GRAPH-002 Error

Dependency Cycle

Circular dependency across import/require/dynamic-import edges. Extract shared logic into a third module.

OB-GRAPH-003 Warning

Unresolved Spec Citation

OpenSpec markdown references a path with no matching node. Fixed automatically for api/* → backend/src/routes/*.

OB-GRAPH-004 / 005 Warning / Strict Error

Orphaned Code & Test Coverage Gap

Orphaned code (zero inbound imports) or test coverage gaps (no test file referencing the module).
