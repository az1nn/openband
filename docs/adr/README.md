# Architecture Decision Records

Create an ADR only for a consequential, durable decision: a new/removed boundary, responsibility shift, persistence strategy, cross-runtime protocol, structural dependency/technology choice, costly-to-reverse choice, or supersession of an earlier decision.

Use `YYYY-MM-DD-<slug>.md` with: **Context, Decision, Consequences, Alternatives**.

Do not create ADRs merely because a template exists. Supersede old ADRs explicitly; do not rewrite history.
