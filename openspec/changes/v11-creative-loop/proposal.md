# Proposal — V11 Creative Loop
## Status
PROPOSED / REGENERATED

## Problem
O usuário precisa ouvir e iterar sobre uma ideia antes de criar um projeto.

## Goal
```text
configure → generate → preview → adjust → lock → regenerate → compare → select → approve → exact create
```

## Correctness goals
- identity taxonomy explícita;
- musical equality verificável;
- stable role locks;
- bounded preview;
- race-safe generation;
- durable idempotent promotion;
- session-scoped ephemeral persistence;
- safe audio lifecycle.

## Non-goals
Prompt-to-Music, Arrangement Composer, collaboration, export rewrite, native plugin platform.
